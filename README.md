# 🎬 MovieTime  
25년도 2학기 **웹프로그래밍** 과목 개인 프로젝트

---

## 📌 프로젝트 개요

MovieTime은 영화 예매 및 정보 제공 웹서비스입니다.  
사용자는 영화 목록을 확인하고, 상세 정보 조회, 예매, 마이페이지 확인 등 다양한 기능을 웹에서 수행할 수 있습니다.

---

## 🚀 기능 구성

✔ 영화 목록 조회  
✔ 영화 상세 정보 보기  
✔ 영화 검색  
✔ 회원가입 / 로그인 / 로그아웃  
✔ 좌석 선택 및 예매 처리  
✔ 예매 내역 확인  
✔ 즐겨찾기 기능  
✔ 마이페이지 – 사용자 정보 수정

---# 🎬 MovieTime

PHP와 MySQL을 활용하여 제작한 영화 예매 웹사이트 프로젝트입니다.  
사용자는 영화 정보를 조회하고, 회원가입 후 로그인하여 좌석을 선택하고 예매할 수 있습니다.

> 25년도 2학기 웹프로그래밍 개인 프로젝트

---

## 📌 프로젝트 소개

**MovieTime**은 영화관 웹사이트를 모티브로 제작된 동적 웹 애플리케이션입니다.  
사용자 인증, 영화 검색, 좌석 선택, 예매 처리, 마이페이지 기능을 구현하였습니다.

---

## 🚀 주요 기능

### 👤 회원 기능
- 회원가입
- 로그인 / 로그아웃
- 세션 기반 사용자 인증
- 마이페이지 정보 확인 및 수정

### 🎥 영화 기능
- 영화 목록 조회
- 영화 상세 정보 페이지
- 영화 검색 기능
- 영화 즐겨찾기(Like) 기능

### 🎟 예매 기능
- 영화 선택
- 좌석 선택
- 예매 처리 및 완료 페이지
- 내 예매 내역 조회
